# Glacier Ecosystems

An interactive data visualization exploring the relationships between glaciers and their surrounding environments.

## Project

This project explores the evolution of glaciers and their relationships with ecosystems, the enviroment,  human communities and industries.

## Objectives

- Explore relationships between glaciers and environmental systems.
- Understand how these relationships evolve over time.
- Explore possible future scenarios.

## Data Sources

- GLAMOS (Glacier Monitoring in Switzerland)
- CAMELS-CH (hydro-meteorological time series and landscape attributes for 331 catchments in hydrologic Switzerland)

## Shared interactions

Drag to orbit, pan to move sideways, and zoom to inspect detail. A drag must not trigger a click. Click any visible glacier, river, actor, relationship or dated outline to open its information card. Close the card to continue exploring from the same position. If its object is hidden, clear the selection. Changing the year updates the open card. Preserve camera position and layer choices across dates. Optional terrain provides geographic context beneath the abstract scene.
